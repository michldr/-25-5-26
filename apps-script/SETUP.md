# הוראות עדכון צד השרת (Apps Script)

הדף החדש עובד רק אחרי שמעדכנים את הקוד ב-Apps Script. כדאי לעשות את זה **לפני** שמפרסמים את הדף החדש. כל התהליך לוקח כ-10 דקות.

## 1. פתיחת עורך הסקריפט
1. פתחי את הגיליון (Google Sheets) שאליו נשמרות ההרשמות.
2. בתפריט: **תוספים (Extensions) ← Apps Script**.

## 2. החלפת הקוד
1. בקובץ `Code.gs` בעורך: סמני הכל (Ctrl+A) ומחקי.
2. הדביקי את כל התוכן של הקובץ `apps-script/Code.gs` מהפרויקט הזה.
3. שמרי (Ctrl+S).

## 3. הגדרת סיסמת מנהל
הסיסמה נשמרת עכשיו בשרת בלבד, ולא מופיעה בדף.
1. בעורך, בתפריט הצד: **הגדרות הפרויקט (Project Settings)**, סמל גלגל השיניים.
2. גללי למטה אל **מאפייני סקריפט (Script Properties)** ← **הוספת מאפיין**.
3. שם המאפיין: `ADMIN_PASSWORD`. ערך: סיסמה חדשה לבחירתך (לא 1234).
4. שמרי.

## 4. פרסום גרסה חדשה (באותה כתובת)
1. למעלה מימין: **פריסה (Deploy) ← ניהול פריסות (Manage deployments)**.
2. לחצי על סמל העיפרון (עריכה) של הפריסה הקיימת.
3. בשדה **גרסה (Version)** בחרי **גרסה חדשה (New version)**.
4. ודאי ש-"Execute as" הוא **Me** וש-"Who has access" הוא **Anyone**.
5. לחצי **פריסה (Deploy)**. אם גוגל מבקשת לאשר הרשאות, אשרי.

> חשוב: **אל תבחרי "New deployment"**. פריסה חדשה יוצרת כתובת חדשה, ואז צריך לעדכן אותה גם ב-`index.html` (המשתנה `WEB_APP_URL`).

## 5. בדיקה
אחרי העדכון, הקוד יוצר בגיליון לשונית חדשה בשם **"הרשמות"** בהרשמה הראשונה. הלשונית הישנה לא נמחקת, ואפשר למחוק אותה ידנית.

כדי לבדוק שהשרת עובד, פתחי בדפדפן את כתובת ה-Web App. אמורה להופיע השורה:
```
{"ok":true,"taken":[]}
```
אם זה מופיע, אפשר לפרסם את הדף החדש.

## מה השתנה
| לפני | אחרי |
|---|---|
| סיסמת המנהל (1234) גלויה בקוד הדף | הסיסמה נבדקת בשרת ונשמרת בהגדרות הסקריפט |
| ביטול לפי הקלדת שם ההורה | לוחצים על השעה הרשומה ומאשרים את הביטול |
| שני הורים יכולים לתפוס אותה שעה בו-זמנית | השרת נועל ובודק לפני שמירה; השני מקבל הודעה לבחור שעה אחרת |
| בכל שעה תפוסה מופיעים שם ההורה ושם הילד/ה | בכל שעה תפוסה מופיע שם הילד/ה; שם ההורה מופיע בכניסת מנהל ובגיליון |
| חלונות קופצים של הדפדפן | טופס נוח בתוך הדף, מותאם לטלפון |
| אותו ילד יכול להירשם פעמיים | השרת חוסם הרשמה כפולה של אותו ילד (עם אותו הורה) |
